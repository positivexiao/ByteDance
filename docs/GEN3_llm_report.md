# 本地端侧大模型评测报告

## 接入概况

- 推理底座：llama.cpp Android library
- App 模型来源：远端豆包模型 / 本地 llama.cpp 模型
- 本地能力范围：仅支持文本对话

## 已确认模型参数

- 模型：Qwen2.5-0.5B-Instruct GGUF
- 量化：Q4_K_M
- 上下文长度：2048
- 最大生成长度：512
- 温度：0.7
- Top P：0.9
- 线程数：4

## 测试环境

- 设备型号：高通骁龙8 Gen3
- Android 版本：16 (API 36)
- CPU 核心数：8
- 设备总内存：15204 MB
- ABI：arm64-v8a
- 模型文件：qwen2.5-0.5b-instruct-q4_k_m.gguf
- 模型文件大小：468.64 MB
- APK 构建类型：debug
