当前 llama.cpp Android 示例库只暴露 `predictLength` 给 Kotlin 层，其余参数先在设置页展示；如需真实生效，需要继续扩展 native `ai_chat.cpp` 参数接口。

## 如何生成报告

1. 在 **设置** 页选择并复制 GGUF 模型到私有目录（可选：点击「加载本地模型」）
2. 进入 **设置 → 本地模型性能评测**
3. 点击 **开始性能评测**，等待完成（约 2–8 分钟）
4. 点击 **复制 Markdown 报告**，粘贴到本文件或提交作业

评测说明：

- **模型加载耗时**：卸载后重新加载实测，比单次点击「加载」更准确
- **首 token 延迟**：真实对话链路，固定问题重复 3 次取平均
- **生成速度 tokens/s**：调用 llama.cpp 原生 `bench(tg=128, nr=3)`，比手工计时更准确
- **峰值内存**：评测全程采样 PSS（`Debug.getMemoryInfo`）
- **效果评测（8 题）**：可选开关；每题前重置 native 上下文，并使用针对小模型优化的 prompt
